Number and stamp the pages

Writes a small pencil-style number at a corner of each page — the same numbering you pencil onto originals before filing — and, if you want, a line of custom text anywhere on the page and a watermark. All three are drawn as ink on top of the page, so the scan is never re-encoded: no loss of quality, and the file grows by a few KB. Blank pages are left unnumbered.

Fill & edit

Type into a form, tick boxes, attach a photo or signature, draw a box or line, white-out or highlight — anywhere on any page. New text takes the font, size and colour of the text beside where you click, and lines up with it, so it reads as part of the page. Everything is drawn as real text and lines on top of the page; the page itself is not redrawn.

Press Show page to open the first page.
Pick a tool above and click the page. Click an item with Select to change it.
When there is nothing to match
Delete removes · Ctrl+Z undo · Ctrl+D duplicate · arrows nudge (Shift: 10) · Shift while drawing a line keeps it straight · double-click text to edit it
The match uses the nearest of the fonts every PDF reader carries — Helvetica (the Arial family), Times or Courier — in the same weight, slant, size and colour. A PDF keeps only the letters it already uses from its own font, so the original font itself cannot be reused for new words; on a typed form the difference is rarely visible. On a scanned page there is no text to read, so the size is measured from the line of ink beside your click.

Photo, signature & documents for forms

Every application asks for a different size. A photograph, a signature, or a document — an Aadhaar or PAN card, a certificate, any paper or picture. Set what the form wants once — in mm, cm, inches or pixels — and the picture is cropped, cleaned and saved to exactly that size, resolution and file size. The picture never leaves this device.
