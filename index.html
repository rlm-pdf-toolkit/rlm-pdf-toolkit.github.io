Page order

Type the order using current positions (not original page numbers). A reversed range such as 9-5 reverses those pages.

Number and stamp the pages

Writes a small pencil-style number at a corner of each page — the same numbering you pencil onto originals before filing — and, if you want, a line of custom text anywhere on the page and a watermark. All three are drawn as ink on top of the page, so the scan is never re-encoded: no loss of quality, and the file grows by a few KB. Blank pages are left unnumbered.
